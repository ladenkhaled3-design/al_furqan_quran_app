# AI Rules

## Project

Quran application built with FlutterFlow / Flutter.

## Core Goals

- Arabic first
- RTL
- Offline-first
- Fast
- Maintainable
- Scalable
- Production ready

## MVP

- Home
- Surah List
- Quran Reader
- Offline Quran
- Search
- Bookmarks
- Last Reading
- Settings

## Later

- Audio
- Tafsir
- Translation
- Azkar
- Prayer Times
- Qibla

## Engineering Rules

- Inspect existing code first.
- Reuse existing code.
- Avoid unnecessary files.
- Avoid unnecessary dependencies.
- Do not duplicate logic.
- Do not modify unrelated features.
- Do not use fake Quran content.
- Preserve RTL.
- Optimize for mobile performance.
- Keep UI and business logic separated.
- Prefer simple solutions.
- Do not change architecture without justification.

## Communication

Be concise.

Do not repeat project documentation.

Only report relevant changes.
